# Unstable // Locator

Fan-made Unstable SMP / Unstable Universe GeoGuessr-style browser game.

## Modes

- Geo Guess
- Guess the POV
- Guess the Arc
- Who Visited?
- Place It
- Timeline Duel
- **1v1 Multiplayer**

## 1v1 Multiplayer

1v1 mode is browser-to-browser using WebRTC with PeerJS signaling. One player creates a six-character room code and another player joins it. Both players receive the same rounds. Correct answers score 1,000 points plus a speed bonus.
